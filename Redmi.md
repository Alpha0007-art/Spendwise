# SpendWise 💰

SpendWise is a simple web application that helps users analyze their personal expenses from a CSV file and gain insights into their spending habits.

Built using Python and Streamlit, the app allows users to upload expense data and instantly visualize spending patterns through charts and smart suggestions.

---

## Features

- Upload expense data using CSV files
- Automatic spending analysis
- Category-wise expense visualization
- Identify the highest expense
- Smart spending advice based on total spending
- Admin mode for viewing error logs and activity

---

## Tech Stack

- Python
- Streamlit
- Pandas
- Matplotlib

---

## How to Run Locally

1. Clone the repository

```
git clone https://github.com/yourusername/spendwise.git
```

2. Install dependencies

```
pip install -r requirements.txt
```

3. Run the app

```
streamlit run app.py
```
